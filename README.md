## المعمارية الهندسية والإنتاجية (Production Architecture)

- **نمط النظام:** Single-Tenant Architecture (مشروع Firebase مستقل تماماً وخاص بمركز ASCPT).
- **قاعدة البيانات السحابية:** Cloud Firestore بنظام المجموعات المباشرة:
  - `patients/{patientId}`: ملفات المرضى والشيتات الطبية السريرية.
  - `sessions/{sessionId}`: تسجيل حضور الجلسات وتوريد المبالغ ونسب التحمل.
  - `expenses/{expenseId}`: مصروفات المركز (خاصة بالإدارة فقط).
  - `users/{uid}`: حسابات وبيانات الطاقم الطبي والإداري.
  - `audit_logs/{logId}`: سجل رقابي وتدقيق محمي وموثوق من جهة الخادم.
- **الأمان والصلاحيات (Security & RBAC):**
  - اعتماد قواعد أمان صارمة في Cloud Firestore Security Rules بنمط Fail-Closed لمنع أي وصول غير مصرح به.
  - إدارة الحسابات وإضافة وتعديل وحذف الموظفين تتم حصرياً عبر نقطة نهاية خادم محمية (`/api/admin/users`) بواسطة Firebase Admin SDK.
- **العمل دون اتصال (Offline-First Resilience):**
  - تفعيل التخزين المؤقت المحلي متعدد النوافذ عبر Cloud Firestore IndexedDB Persistent Cache.
- **نظام التصدير والطباعة:**
  - محرك تصدير الإكسيل المعتمد لتقارير الإيرادات اليومية والشهرية بدقة وتصنيف كامل.
