# PhysioFlow Demo - نظام إدارة مراكز العلاج الطبيعي والتأهيل (نسخة العرض)

نسخة تجريبية تفاعلية شاملة لبرنامج إدارة مراكز وعيادات العلاج الطبيعي، مصممة للعرض والمبيعات.
- محملة بـ 185 مريض، 635 جلسة على مدار شهرين، ومصروفات وسجلات شيتات العلاج الطبيعي.
- تعمل تلقائياً على أي متصفح كـ PWA على الموبايل والكمبيوتر.
- معزولة تماماً في ذاكرة المتصفح لكل زائر لضمان عدم تداخل التجارب.

## تنبيه هام بخصوص طبيعة النسخة التجريبية (Demo Notice)

- **طبيعة النسخة:** هذه نسخة تجريبية (Demo) مخصصة للمعاينة والعرض فقط وليست نسخة إنتاجية.
- **البيانات المدرجة:** جميع البيانات الموجودة داخل التطبيق (المرضى، الجلسات، الحسابات، الأرقام) هي بيانات تجريبية وهمية لأغراض العرض التوضيحي وليست بيانات مرضى حقيقية.
- **سرية البيانات:** يرجى عدم إدخال أي بيانات مرضى حقيقية أو أي بيانات شخصية أو طبية حساسة في هذه النسخة.
- **نظام تسجيل الدخول (Authentication):** نظام المصادقة وتبديل الأدوار الحالي هو Demo Authentication تجريبي لتجربة واجهات وصلاحيات الأدوار المختلفة، وليس نظام Authentication إنتاجياً.
- **تخزين البيانات:** جميع البيانات والعمليات محفوظة محلياً داخل المتصفح (LocalStorage) لكل مستخدم بشكل معزول ومستقل.
- **النسخة الإنتاجية / التجارية:** النسخة التجارية المخصصة للعيادات والمراكز تعتمد على قاعدة بيانات سحابية حقيقية مشفرة (Backend) ونظام مصادقة وأمان وصلاحيات إنتاجي متكامل (Production Auth & Security).
